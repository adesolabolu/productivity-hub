# ⚡ Productivity Hub

A sleek, offline-first personal productivity dashboard for managing tasks, notes, checklists, and priorities.

🔗 **Live Demo:** [to-do-list-app-phi-ochre.vercel.app](https://to-do-list-app-phi-ochre.vercel.app)

---

## ✨ Features

- **Task Management**: Create, edit, prioritize (High / Medium / Low), and set due dates for tasks.
- **Interactive Subtasks**: Breakdown tasks into checklists; auto-completes subtasks when a parent task is checked.
- **Markdown Notes**: Rich markdown note-taking powered by `marked.js`.
- **Organization & Filters**: Tagging system (`#work`, `#personal`, etc.), pin important items, archive completed tasks, and instant live search.
- **100% Client-Side & Offline**: Powered completely by browser `localStorage` — no backend server or database setup required.
- **Mobile Optimized**: Responsive design with a sliding sidebar and a dedicated mobile bottom navigation bar.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Optional: serve with any static server
npx serve .
```
